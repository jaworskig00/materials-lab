# Materials Lab

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Approved: Vite, React 19, TypeScript, Tailwind, Zustand, Three.js, React Three Fiber 9, D3; Python training and ONNX browser inference.

## Users
Researchers comparing documented aluminium tensile properties with local laboratory measurements.

## Product Purpose
Explore a traceable materials dataset, compare surrogate predictions and experimental values, and understand prediction uncertainty. Civilian tensile testing only. No ballistic performance, weapon parameters, inverse design, or composition optimization.

## Operating Context
English interface. Desktop-led, responsive. Standard tensile specimen shown as a schematic 3D procedure, not a finite-element or fracture simulation. Catalogue-constrained inputs; no invented alloy names or unsupported test-condition controls. Up to four comparisons. CSV data stays in the browser.

## Capabilities and Constraints
Yield strength, tensile strength, elongation. Real source data, grouped validation, calibrated prediction intervals, model provenance. No cloud inference, accounts, remote analytics, or automatic training on user data.

## Brand Commitments
Approved dark neutral laboratory, restrained colours, precise units, visible distinction between measured and predicted values. Code-first build. No marketing landing page.

## Evidence on Hand
Bhat, Barnard and Birbilis, Mendeley dataset b6br4yk6r3 version 1, CC BY 4.0. Original CSV retained with publisher SHA256. No independent laboratory validation.

## Delivery
Initial implementation and local tests preceded the first private push. On 2026-10-28 the owner authorized public release and GitHub Pages after documentation, license and repository-metadata review. Future deployments remain manual, from reviewed release tags.

## Accessibility & Inclusion
Keyboard controls, visible focus, reduced motion, responsive layout, WebGL fallback, textual data alternatives.
