Continuity: Mount → Pull → Hold, with direct stage selection and scrubbing. This sequence is the same for every catalogue record; it is deliberately exaggerated and independent of all model predictions. No stress field, fracture, force or physical strain is inferred.

Feedback: Play/Pause/Replay, reset, playback speed, camera presets and an original-outline toggle. Current phase has a short explanation. All controls work with the keyboard.

Budget: one existing WebGL canvas, demand rendering when idle, bounded geometry updates during user-started playback. No new runtime dependencies. Pause when hidden or offscreen; reduced motion retains manual snapshots and camera presets.
