# Security reporting

For a suspected vulnerability, use GitHub's private **Report a vulnerability** form under the repository's Security tab:

https://github.com/jaworskig00/materials-lab/security/advisories/new

Include affected versions, reproduction steps and the likely impact. Do not put credentials, private CSV files or exploit details in a public issue. Ordinary reproducible bugs belong in Issues, using synthetic data when needed.

Security fixes target the latest release. This is a community research project with no guaranteed response time or long-term support commitment. Scientific accuracy or model-support concerns can be reported as ordinary issues without private data.
